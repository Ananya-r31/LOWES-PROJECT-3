# Neon Drum Pad Machine

## Description

A React-based interactive drum pad machine that allows users to play drum sounds using mouse clicks or keyboard keys.

## Features

- 9 drum pads
- Keyboard controls
- Mouse controls
- Master volume
- Power toggle
- Digital display
- Neon animations
- React Hooks
- HTML5 Audio

## Keyboard Controls

| Key | Sound |
|-----|-------|
| Q | Kick |
| W | Snare |
| E | Hi-Hat |
| A | Clap |
| S | Tom |
| D | Open Hi-Hat |
| Z | Low Tom |
| X | Crash |
| C | Ride |

## Technologies

- React
- JavaScript
- CSS
- HTML5 Audio API

## How to Run

```bash
npm install
npm run dev
```

## Audio files

Sounds are in `public/audio/` (kick.mp3, snare.mp3, ...). They are simple synthesized drum sounds. To use your own, replace the files with the same names.
